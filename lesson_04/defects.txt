Отчёт о дефектах в классе StringUtils

Дефект 1: метод trim удаляет только пробелы в начале строки

Описание: метод удаляет только обычные пробелы (" ") в начале строки. Он не обрабатывает:

табуляции (\t);

переносы строк (\n);

пробелы в конце строки.

Пример: trim("\t\tskypro") вернёт "\t\tskypro".

Рекомендация: использовать string.lstrip() вместо текущей реализации.

Дефект 2: метод contains содержит избыточную логику

Описание: использование string.index() с обработкой исключения ValueError излишне усложняет код.

Проблема: метод index() выбрасывает исключение, если символ не найден, что требует обработки исключений.

Решение: заменить на простое symbol in string.

Дефект 3: метод delete_symbol выполняет избыточную проверку

Описание: перед вызовом replace() метод проверяет наличие символа через contains().

Проблема: replace() сам по себе безопасен — если подстрока не найдена, он просто вернёт исходную строку без изменений.

Рекомендация: убрать проверку if self.contains(string, symbol):.

Дефект 4: метод capitalize не обрабатывает None

Описание: при передаче None в метод capitalize() возникнет AttributeError.

Рекомендация: добавить проверку на None и выбросить осмысленное исключение или вернуть None.
